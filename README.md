# Proyectos destacados

## SaaS de Fichajes

Sistema multiempresa de control horario desarrollado para entornos reales de trabajo.

Incluye gestión de empleados, solicitudes, exportaciones profesionales, trazabilidad de acciones, auditoría de logs y funcionalidades orientadas al cumplimiento laboral y operativo.

El proyecto está planteado como un producto escalable y preparado para uso empresarial real.

**Stack:** FastAPI · React · PostgreSQL · TailwindCSS

---

## Automatización de operaciones formativas

Plataforma orientada a automatizar procesos administrativos relacionados con altas de alumnos y validación de datos.

El sistema transforma procesos manuales basados en correos, Excel y generación de CSV en un flujo más estructurado mediante automatizaciones, validaciones y workflows internos.

Incluye integración con almacenamiento, tratamiento de archivos y automatización de comunicaciones.

**Stack:** FastAPI · React · Supabase · n8n

---

## Plataforma ISO 9001

Software orientado a digitalizar procesos de auditoría, gestión documental y seguimiento operativo en entornos de consultoría ISO.

El proyecto busca sustituir procesos manuales y documentación dispersa por una plataforma más organizada, visual y preparada para trabajo continuo.

Incluye módulos relacionados con auditorías, tareas, documentos y flujos internos de seguimiento.

**Stack:** React · FastAPI · PostgreSQL

---

## Web oficial C.F.S. Femenino San Fernando

Desarrollo de una plataforma web moderna para un club deportivo femenino, centrada en mejorar su presencia digital y ofrecer una imagen más profesional de cara a patrocinadores, comunicación y crecimiento futuro.

El proyecto trabaja especialmente el diseño visual, la adaptación responsive y la integración de elementos comerciales y de monetización.

También se planteó con una estructura preparada para futuras ampliaciones relacionadas con tienda, campañas y gestión digital del club.

**Stack:** Next.js · TailwindCSS · Stripe
